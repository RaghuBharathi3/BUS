# Authoritative Sources & Standards — Safar Project

This document catalogs all verified technical specifications, IEEE/ACM publications, and W3C recommendations referenced throughout the research and documentation suite.

---

## 1. Academic Peer-Reviewed Literature

1. **Mohammed & Kassem (2020)**
   - *Title*: UML Modeling of Online Public Bus Reservation System in Egypt
   - *Venue*: 2020 International Conference on Data Analytics for Business and Industry (ICDABI), IEEE
   - *DOI*: `10.1109/ICDABI51230.2020.9325604`
   - *Usage*: Object-oriented architecture and UML decomposition models.

2. **Abu-Dalbouh & Alateyah (2020)**
   - *Title*: An Extension to UML for the Modeling of Web Based Bus Reservation System
   - *Venue*: Journal of Computer Science, Science Publications
   - *DOI*: `10.3844/jcssp.2020.825.837`
   - *Usage*: Web-specific modal sequence diagram stereotypes.

3. **Naeem (2019)**
   - *Title*: Performance Evaluation of Progressive Web Apps and Single Page Applications
   - *Venue*: 2019 22nd International Multitopic Conference (INMIC), IEEE
   - *DOI*: `10.1109/INMIC48123.2019.9022759`
   - *Usage*: Single Page Application latency and bandwidth benchmarks.

4. **Pedone (2001)**
   - *Title*: Optimistic validation of electronic tickets
   - *Venue*: Proceedings 20th IEEE Symposium on Reliable Distributed Systems (SRDS), IEEE
   - *DOI*: `10.1109/RELDIS.2001.970764`
   - *Usage*: Optimistic reservation and local state buffer decoupling.

5. **Chawathe (2010)**
   - *Title*: Organizing transit data for efficient search and dissemination
   - *Venue*: 2010 IEEE 13th International Conference on Intelligent Transportation Systems (ITSC), IEEE
   - *DOI*: `10.1109/ITSC.2010.5625055`
   - *Usage*: Algorithmic transit indexing and route modeling.

6. **Tirumala (2023)**
   - *Title*: Smart Bus Pass Management System
   - *Venue*: 2023 3rd International Conference on Innovative Sustainable Computational Technologies (CISCT), IEEE
   - *DOI*: `10.1109/CISCT57197.2023.10351336`
   - *Usage*: Digital ticket verification and student pass lifecycles.

7. **Kim (2021)**
   - *Title*: Proactive Debugging of Memory Leakage Bugs in Single Page Web Applications
   - *Venue*: IEEE Transactions on Software Engineering
   - *DOI*: `10.1109/TSE.2021.3097275`
   - *Usage*: Single Page Application memory lifecycle management.
